Aula 04 — Transições ε (visuais)

ε muda de estado sem consumir entrada. Serve para montar união, concatenação e fechamento (*). Base: L1 = ab · L2 = ba.

← Aula 03 · Aula 05 →

círculo duplo = final ε = transição nula (tracejada roxa) seta solta = inicial

0. Peças base

L1 = ab   ·   L2 = ba

1. União — L1 ∪ L2 = ab + ba

Novo inicial →ε→ A e →ε→ D

Receita: novo S · ε para cada inicial · finais de L1 e L2 continuam finais.

2. Concatenação — L1 · L2 = abba

Final de L1 →ε→ inicial de L2

Receita: cole o final de L1 no inicial de L2 com ε. Só F é final.

3. Fechamento — L1* = (ab)*

Novo inicial (final) →ε→ A · C →ε→ A (loop) · C final

Aceita: ε, ab, abab · Rejeita: a, aba, ba

4. Remover ε — fecho-ε

fecho-ε(q) = q + tudo alcançável só com ε
